## 🌟 Executive Overview

**Canine AI Whisperer** bridges the communication gap between dogs and humans by translating physical micro-signals, acoustic vocalizations, and behavioral telemetry into actionable, real-time veterinary ethology guidance.

Preventing behavioral escalation, separation anxiety crises, and fear-based aggression requires understanding the subtle antecedent cues dogs emit before barking or biting. By combining **Google Gemini Multimodal Vision AI**, **Web Audio bio-acoustic FFT spectral analysis**, **Snowflake Cortex ML predictive models**, and **Solana on-chain digital credentialing**, this platform provides dog parents, veterinary behaviorists, and trainers with enterprise-grade canine intelligence.

### 1. Multimodal Canine Vision Decoder
- **Real-Time Camera & Photo Ingestion**: Streams live WebRTC video or processes uploaded canine images via `FileReader` decoding.
- **Micro-Marker Anatomical Breakdown**: Evaluates ear base tension, commissure retraction (pant/grimace), whale eye (sclera exposure), tail angle/stiffness, pupil dilation, and weight distribution.
- **Clinical Ethology Scoring**: Calculates precise Arousal Scores ($0-100$), Cortisol Risk Bands (Low/Moderate/Elevated/Critical), and immediate de-escalation protocols.
- **Instant Synchronization**: Pushes telemetry to the Snowflake warehouse and issues Solana `TREATS` rewards upon analysis completion.

### 2. Acoustic Bark Spectrogram & Harmonic Analyzer
- **Real-Time Microphone FFT Capture**: Captures live audio streams via the HTML5 MediaDevices API and renders high-resolution frequency domain waveforms.
- **Acoustic Harmonics Decoding**: Analyzes fundamental frequency ($F_0$ in Hz), sound pressure level (dB), cadence duration, and spectral entropy.
- **Emotional Motivation Classifier**: Categorizes vocalizations into Alert/Territorial, Separation Distress, Demand/Attention, Fear-Anxiety, and Predatory Excitement with human-readable intent translations.
- **Acoustic Redirection**: Triggers immediate double-pulse ultrasonic intervention signals to interrupt hyper-arousal loops.

### 3. Neural Dog Voice Synthesizer
- **Tailored Ethological Personas**: Choose from distinct personality profiles:
  - *The Golden Goof* (Eager, food-motivated, warm)
  - *The Bulldog Lord* (Grumpy, sleepy, dignified)
  - *The Shepherd Guardian* (Vigilant, tactical, protective)
  - *The Frenchie Sassy* (Demanding, playful, vocal)
  - *The Husky Dramatic* (Theatrical, vocal, rebellious)
  - *The Whisperer Sage* (Calm, assertive, grounding)
- **Neural Text-to-Speech**: Renders expressive canine inner thoughts with adjustable pitch, tempo, and emotional tone.

### 4. Ultrasonic Whistle & Restorative Sound Studio
- **High-Frequency Tone Generator**: Operates between $8,000\text{ Hz}$ and $22,000\text{ Hz}$ with adjustable gain modulation.
- **Standard Emergency Signals**:
  - *Emergency Recall Burst* ($16,500\text{ Hz}$ triple staccato)
  - *Stop Barking Signal* ($18,200\text{ Hz}$ sharp pulse)
  - *Attention Click / Check-in* ($14,000\text{ Hz}$ single tone)
  - *Release / Free Cue* ($12,500\text{ Hz}$ gentle bell tone)
- **Restorative Sound Therapy**: Continuous soothing sine wave synthesizer delivering $432\text{ Hz}$ (Delta State Calm), $528\text{ Hz}$ (Cellular Repair), $396\text{ Hz}$ (Thunderstorm Panic Release), and a $60\text{ BPM}$ Maternal Heartbeat Simulator.

### 5. Snowflake Data Cloud & Cortex ML Analytics
- **Cross-Breed Telemetry Warehouse**: Aggregates behavioral records across 80+ breeds ($74,000+$ reference points).
- **Predictive ML Analytics**: Interactive Recharts visualizations of arousal vs. settle recovery curves, hourly barking probability forecasts, and primary trigger distributions.
- **Snowflake SQL Query Studio**: Query editor preloaded with behavioral queries (Anxiety Spike Correlations, De-escalation Effectiveness, Thunderstorm Barometric Forecasting).
- **Live Event Stream**: Real-time searchable and filterable database logs (`CANINE_TELEMETRY.BEHAVIOR_LOGS`).

### 6. Solana Canine Digital Passport & Token Economy
- **On-Chain Digital Identity (cNFT)**: Immutable passport storing microchip SHA-256 signatures, pedigree vitals, and AKC/CGC certification tiers.
- **Verifiable Credentials**: On-chain verifiable badges with cryptographic signature tracking.
- **`TREATS` Micro-Rewards & Quests**: Interactive quest engine rewarding good behavior milestones (*Quiet Crate 20-Min Streak*, *Doorbell De-escalation*, *Loose-Leash Walking*).
- **Cluster Management**: Integrated Devnet faucet simulator for instant SOL balance replenishment.

### 7. Cesar Millan Ethology Coaching Dialogue
- **Cesar Millan Methodology**: Core pack leadership framework (*Exercise, Discipline, Affection* in strict order).
- **Interactive Multi-Turn Chat**: Veterinary advice powered by Gemini 2.5, addressing resource guarding, leash reactivity, barrier frustration, and threshold manners.
- **Voice Response Option**: Listen to audible coaching advice directly in the browser.

The user interface follows an **Editorial Aesthetic**:
- **Palette**: Warm ivory background (`#FAF9F6`) with high-contrast ink text (`#1A1A1A`) and subtle bone-toned containers.

## 🚀 Getting Started

### Prerequisites
- **Node.js**: v18.0.0 or higher
- **npm** or **bun** / **yarn**

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/your-username/canine-ai-whisperer.git
   cd canine-ai-whisperer
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

### Environment Variables

Create a `.env` file in the root directory (based on `.env.example`):

```env
# Google Gemini API Key for Vision & Chat Coach
GEMINI_API_KEY=your_gemini_api_key_here

# (Optional) ElevenLabs Neural TTS API Key
ELEVENLABS_API_KEY=your_elevenlabs_api_key_here

# Server Port (defaults to 3000)
PORT=3000
```

### Running the Application

- **Development Mode (Vite + Express):**
  ```bash
  npm run dev
  ```
  Open [http://localhost:3000](http://localhost:3000) in your browser.

- **Production Build:**
  ```bash
  npm run build
  npm start
  ```

- **Type Check / Lint:**
  ```bash
  npm run lint
  ```

## 📊 Data Model & Telemetry Schema

The Snowflake telemetry stream standardizes canine behavioral events into the following schema:

```sql
CREATE OR REPLACE TABLE CANINE_TELEMETRY.BEHAVIOR_LOGS (
    RECORD_ID           VARCHAR(32) PRIMARY KEY,
    TIMESTAMP           TIMESTAMP_NTZ DEFAULT CURRENT_TIMESTAMP(),
    DOG_ID              VARCHAR(16),
    BREED               VARCHAR(64),
    TRIGGER_TYPE        VARCHAR(48), -- 'Doorbell', 'Mailman', 'Thunder', 'Separation', etc.
    HEART_RATE_BPM      INTEGER,
    AROUSAL_SCORE       INTEGER,     -- Scale 0-100
    RECOVERY_TIME_SEC   INTEGER,     -- Time to return to baseline
    CORTEX_ANXIETY_FLAG BOOLEAN,     -- Snowflake Cortex ML prediction
    ACOUSTIC_HZ_PEAK    FLOAT,
    SOLANA_SIGNATURE    VARCHAR(88)
);
```
